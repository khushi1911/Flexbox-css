# Price Card using Flexbox

A simple pricing card layout created using **HTML and CSS Flexbox**.

## Features

* Clean pricing card design
* Flexbox-based layout
* Responsive structure
* Styled pricing and feature sections

## Technologies Used

* HTML
* CSS
* CSS Flexbox

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Purpose

This project was created to practice **CSS Flexbox, layouts, alignment, spacing, and responsive web design**.
